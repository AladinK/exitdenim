# Arhiva: migracije iz Lovable perioda

Ovo su originalne SQL migracije onako kako ih je pravio Lovable (20 fajlova u
`supabase-migrations/` i 9 u `drizzle/`). Čuvaju se samo kao istorija.

**Ne pokreću se više.** Važeća šema baze je u `supabase/migrations/`, gde je cela
istorija spojena u jedan pregledan fajl (`..._osnovna_sema.sql`).
